# rwlock

В этой задаче вам нужно будет реализовать блокировку чтения--записи с активным ожиданием.
А именно, в `src/sync.rs` нужно доделать определение структуры блокировки
`struct RwLock` и функции для работы с ней.

Пользоваться библиотекой `std` в файле `src/sync.rs` запрещено и не получится.
Вам доступна только `core`, из неё пригодится `core::sync::atomic`.

Для проверки корректности вашего кода с точки зрения модели памяти используется
[Miri](https://github.com/rust-lang/miri):
```
$ rustup component add miri
$ MIRIFLAGS="-Zmiri-disable-isolation" cargo miri test -- --nocapture
```

После того как ваше решение заработает,
попробуйте менять в нём `Ordering`и и смотреть что на это скажет Miri.
Там можно лучше почувствовать модель памяти и освоиться с ней.

В проверочной системе тесты запускаются двумя способами, как под Miri, так и обычным:
```
$ cargo test -- --nocapture
```
